# Changelog

## 1.0.0

Initial public release.

- Direct USB-to-RS232 RNET connection without a TCP serial bridge.
- Home Assistant UI configuration and options flows.
- One media-player entity per configured zone.
- Multiple linked controllers with six-zone mapping per controller.
- Verified power, source and volume commands.
- Automatic serial reconnection and startup probing.
- Unavailable-state handling and connection diagnostics.
- Manual `russound_rnet_local.reset_connection` action.
- HACS metadata, documentation, tests and GitHub validation workflow.
